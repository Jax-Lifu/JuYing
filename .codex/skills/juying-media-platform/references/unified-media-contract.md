# 统一媒体契约速查

完整定义见仓库 [统一媒体契约](../../../../docs/UNIFIED_MEDIA_CONTRACT.md)。本参考只列出实现时最容易被破坏的边界。

## 适配器输入与输出

- 输入：来源配置、用户/儿童策略、设备能力、分类、分页、搜索词或作品/集键。
- 输出：规范化目录条目、详情、季/集、搜索命中、播放描述和来源健康状态。
- 禁止输出给通用层：来源 Cookie、token、抓取选择器、原始类别编码、未校验播放 URL。

## 必须保持的键

- 来源内对象键：`sourceId:sourceItemId`。
- 集键：`sourceId:sourceEpisodeId`；没有集 ID 时使用来源稳定顺序键并标为不稳定。
- 聚类键：可变的展示键，不能作为进度、收藏或播放历史的唯一键。

## 分类

只能输出：电视剧、电影、动画片、纪录片、综艺、直播、少儿、其他。映射规则随来源配置版本化；无法可靠映射时选“其他”。

## 默认 CCTV

默认入口是 CCTV 动画片库：

`https://tv.cctv.com/yxg/index.shtml?spm=C28340.P2qo7O8Q1Led.EEfEAhEnQFPl.64#datacid=dhp&datafl=&datadq=&fc=%E5%8A%A8%E7%94%BB%E7%89%87&dataszm=`

默认分类映射为“动画片”。只使用官网公开、未受保护且当前终端允许的媒体信息；失败时来源级回退官网。
