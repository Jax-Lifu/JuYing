# 联邦搜索规则

## 执行顺序

```text
用户查询 + 来源筛选
  → 过滤启用/授权/可搜索来源
  → 并发扇出并各自限时
  → 规范化命中
  → 应用儿童、地区、设备策略
  → 聚类去重（保留来源版本）
  → 稳定排序与部分失败呈现
```

## 结果规则

- “全部来源”与单源搜索调用同一搜索用例，只是来源筛选集合不同。
- 每个结果显示作品层信息与可展开来源版本；选择某版本才解析该来源的集和播放描述。
- 聚类证据按可靠性排序：外部权威 ID、同源稳定 ID、规范化标题+年份+类型、人工别名。证据不足时宁可不合并。
- 对多源同名内容，保留来源、版本、集数、语言、清晰度、授权/地区可用性。
- 失败来源返回可重试状态、耗时和安全的错误分类；不泄露凭据或内部 URL。

## 排序

顺序为：精确标题/别名匹配、用户来源筛选与优先级、实际可播放性、相关度、时间新鲜度、稳定的标题/来源键兜底。相同查询在同一数据版本下应得到稳定顺序。
