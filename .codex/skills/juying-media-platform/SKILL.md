# 聚映统一多源媒体开发

用于新增或修改媒体来源、来源管理、分类、搜索、详情、选集、播放、播放历史，以及跨端行为。目标是让任何来源通过同一适配器与统一模型服务所有平台。

开始前阅读仓库根目录的 [AGENTS.md](../../../AGENTS.md)。不要把本 Skill 当作绕过内容授权、签名、DRM、地域或终端限制的依据。

## 工作方式

1. 先确定变更属于来源适配、统一模型、联邦搜索、选集、播放会话或平台能力中的哪一层。
2. 先检查来源真实能力、授权状态和平台限制；只实现已声明且允许的能力。
3. 在来源边界完成标准化；UI、搜索和播放器不得读取来源专有字段或通过来源名称分支。
4. 用“单源 → 多选源 → 全部来源 → 来源失败”的路径验证同一功能；任何来源失败都不能破坏其他来源结果。
5. 在交付中明确已验证的平台、未验证的平台、官方回退行为及版权/地区限制。

## 参考路由

- 新增来源、分类映射、统一实体或能力声明时，阅读 [统一媒体契约](references/unified-media-contract.md)。
- 接入第二个来源、NAS、同步、离线下载或准备发布时，阅读 [防返工基础规划](../../../docs/FOUNDATION_PLAN.md)，并确认对应 P0/P1/P2 门禁。
- 设计/实现全局搜索、跨源去重或来源切换时，阅读 [联邦搜索规则](references/federated-search.md)。
- 设计/实现详情、选集、播放和跨平台能力协商时，阅读 [选集与播放器规则](references/episodes-and-player.md)。

## 硬性检查

- 不创建按来源分叉的页面、状态、搜索索引或播放器实现。
- 任何跨源 ID 都必须带 `sourceId` 命名空间；展示聚类不能丢失来源版本。
- 只在来源与设备都声明支持时显示选项；任何未知能力默认禁用。
- 儿童、授权、地区和隐私过滤发生在目录、搜索、历史、推荐与播放候选集之前。
- CCTV 默认入口必须保持为用户指定的动画片库；原生流不可用时回退官网，不以 WebView 代替默认播放器。
