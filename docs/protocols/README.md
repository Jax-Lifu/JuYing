# 协议工程与技术笔记 (Protocol Specifications)

本目录记录项目中涉及的核心网络与流媒体协议的技术备忘与注意事项：
- `dlna-upnp.md`: SSDP 广播发现、AVTransport/RenderingControl 控制服务、GENA 事件订阅。
- `hls-range-proxy.md`: RFC 8216 HLS 分片改写规则与 RFC 9110 HTTP Range 边界处理。
- `m3u-xmltv.md`: Extended M3U 标签扩展属性 (`tvg-*`, `#EXTVLCOPT`, `#EXTHTTP`) 与 XMLTV EPG 时区偏移处理。
- `airplay-reverse.md`: UxPlay 逆向协议架构、GPL 隔离机制与音视频镜像流特征。
