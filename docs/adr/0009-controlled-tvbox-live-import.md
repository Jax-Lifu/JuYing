# ADR-0009：受控 TVBox 直播配置导入

状态：已接受  
日期：2026-08-20  
复审日期：2027-02-20

## 背景

用户需要将自己有权使用的 TVBox 配置接入聚映。该格式可混合直连直播、动态脚本、JAR、网页嗅探、解析服务和代理规则，不能直接成为播放器或领域模型的输入。

## 决定

仅导入 `lives[]` 中声明的、无凭据的直接 HTTP(S) 直播清单，并将 M3U/TXT/JSON 条目转换为统一的直播条目、单集和播放描述。用户须在导入时确认内容权利。配置及清单尺寸和请求时间均受限，播放地址不持久化。

`spider`、`sites`、`parses`、`flags`、`doh`、`rules`、`ads`、`proxy://` 和任何请求头/脚本字段均不会被执行、转发或导入。没有直连 `lives[]` 的配置会被拒绝。

公开 XMLTV 节目表可作为直播来源的可选能力使用。仅持久化经校验的节目表模板；节目单内容按需获取，不进入播放会话或长期媒体索引。

## 后果

`http://xhztv.top/4k.json` 这类配置可在其中存在直连直播清单时接入该直播子集；其点播站、解析服务及动态规则不属于本次兼容范围。配置失效只影响该来源，不会影响默认来源或其他来源。
