# 架构决策记录（ADR）

本目录记录会影响数据形态、来源边界、用户数据、发布范围或不可逆迁移的决定。每个文件使用递增编号，例如 `0001-media-identity.md`。

```markdown
# ADR-0001：标题

状态：提议 / 已接受 / 已替代 / 已废弃
日期：YYYY-MM-DD
复审日期：YYYY-MM-DD

## 背景

要解决的问题、涉及的来源/平台/用户数据，以及不决策的风险。

## 备选方案

列出可行方案及其代价；不要只记录最终方案。

## 决定

明确选择、适用边界和不适用边界。

## 后果与迁移

对统一契约、已有数据、测试、发布、隐私与回滚的影响。

## 验收与复审触发条件

何时证明决定有效；哪些事件必须重新评估。
```

至少为以下主题创建 ADR：媒体/集身份、跨源聚类、家庭与同步、来源生命周期、缓存与迁移、离线许可、播放会话遥测、发布与回滚。详见 [防返工基础规划](../FOUNDATION_PLAN.md)。
