# ADR-0005：缓存、索引与迁移

状态：已接受  
日期：2026-08-19  
复审日期：2027-02-19

## 背景

目录、封面、索引、进度和设置具有不同的失效与隐私要求。

## 备选方案

1. 无版本偏好存储；2. 统一永久缓存；3. 分对象 TTL、schema 与迁移策略。

## 决定

采用方案 3。任何持久化对象必须有 schema 版本、归属 profile 和删除边界；播放 URI 永不持久化。不可回退迁移需先备份/导出。

## 后果与迁移

NAS、搜索索引、历史和设置必须分别定义 TTL、配额、失效和清除流程。

## 验收与复审触发条件

升级、降级、清除档案和撤销来源后无孤儿数据；首次引入数据库时复审。
