# ADR-0001：媒体、来源版本与集身份

状态：已接受  
日期：2026-08-19  
复审日期：2027-02-19

## 背景

多来源可能出现同名作品、重制版、特别篇和不同集序；错误共用 ID 会串进度、收藏和播放。

## 备选方案

1. 用标题作为全局 ID；2. 只保留来源原始 ID；3. 分离作品聚类、来源版本、季/集与播放会话。

## 决定

采用方案 3。`sourceId:sourceItemId` 和 `sourceId:sourceEpisodeId` 是唯一可播放、可持久化身份；作品聚类键只用于展示，不能替换来源版本键。

## 后果与迁移

新增统一 `MediaItem`、`MediaEpisode` 和 `PlaybackDescriptor`。进度、历史、偏好必须迁移到来源集键；播放 URI 不写入长期存储。

## 验收与复审触发条件

两个模拟来源的同名、不同集序、特别篇测试通过；引入权威外部 ID 或人工合并时复审。
