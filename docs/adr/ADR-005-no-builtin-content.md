# ADR-005: 应用自身不内置任何媒体内容与服务源

## 状态
已接受 (Accepted)

## 日期
2026-10-20

## 背景与上下文
作为一款聚合播放器客户端，若在二进制安装包内直接打包、内置、分发第三方流媒体资源、爬虫站源或私人视频链接，将带来极高的法律版权合规风险、应用商店下架风险以及持续维护的沉重负担。

## 决策
1. 客户端严禁内置、分发或运营任何第三方音视频内容服务器、账号体系与媒体源。
2. 应用出厂预设仅提供用户完全可查看、可编辑、可停用、可删除的官方合规示范预设（如 CCTV 官方公开地址示范）。
3. 强化“空状态引导”设计，指导用户通过手动添加源、导入 TVBox 配置、局域网手机推送或扫码配置自己的媒体源。
4. 客户端配备明确的免责声明与隐私协议。

## 原因分析与权衡
1. **法律合规与应用商店准入**：彻底切断与侵权内容的强绑定关系，确保作为纯中立本地播放工具的合规边界。
2. **架构中立性与解耦**：内容与播放器内核完全解耦，第三方源的时效失效不会导致应用自身不可用。

## 何时重审
本决策为项目红线约束，**不重审**。
