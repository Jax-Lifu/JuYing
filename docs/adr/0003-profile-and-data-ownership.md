# ADR-0003：档案、家庭与数据归属

状态：已接受  
日期：2026-08-19  
复审日期：2027-02-19

## 背景

儿童历史、成人偏好和未来同步不能混用。

## 备选方案

1. 单一设备历史；2. 强制账号；3. local-first 档案、同步可选。

## 决定

采用方案 3。默认访客/成人/儿童档案本地隔离；进度、历史、收藏和偏好均带 profile ID。同步、账户和家庭共享在单独 ADR 复审后才实现。

## 后果与迁移

PIN 与凭据只能进入安全存储；儿童搜索建议、历史和自动连播不得进入成人档案。

## 验收与复审触发条件

删除一个儿童档案不得影响其他档案；引入登录、配对或云端时复审。
