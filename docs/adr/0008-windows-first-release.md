# ADR-0008：Windows-first 发布与回滚

状态：已接受  
日期：2026-08-19  
复审日期：2027-02-19

## 背景

当前仅验证 Windows，不能将产品层可复用表述为全平台已发布。

## 备选方案

1. 同时发布所有平台；2. 不做渠道；3. Windows 内测/稳定渠道优先。

## 决定

采用方案 3。Windows 先建立 debug、canary、stable、版本兼容和回滚策略；其他平台保持共享业务契约但明确未验证。

## 后果与迁移

每次 Windows 变更至少格式化、分析、测试和 Debug 构建；发布前才执行 Release 与真实设备矩阵。

## 验收与复审触发条件

来源远程关闭、版本回退和数据迁移观察期演练通过；新增发布平台时复审。
