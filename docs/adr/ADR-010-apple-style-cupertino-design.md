# ADR-010: 采用 Apple 风格设计语言、Cupertino 组件基底与自适应低性能模式

## 状态
已接受 (Accepted) (v0.2 Q11 / 5.11 / N7)

## 日期
2026-10-20

## 背景与上下文
聚映需要在 Windows 10/11 桌面、Android 手机/平板以及 Android TV / 盒子上提供高质感、现代化的视觉交互体验。
指导文档 v0.2 要求视觉语言参考 Apple 风格：充裕留白、大标题导航、层级清晰、深色背景（Cinema Dark）、圆角、半透明毛玻璃（Glassmorphism）、柔和环境阴影与弹性动效。
但在低端 Android TV 盒子（如老旧 armeabi-v7a 芯片）上，实时背景模糊（BackdropFilter）会带来严重的 GPU 填充率压力与掉帧（R15）。

## 决策
1. **组件选型基底**：
   - 尽量复用 Flutter 的 `Cupertino` 设计组件（大标题导航栏、分组列表、分段控件、弹层、操作表），统一应用设计令牌。
   - `ui_kit` 包负责集中收口设计令牌（Design Tokens: 调色板、圆角阶梯、模糊强度、阴影标尺、动效曲线与时长）。
   - 自建 Cupertino 缺乏的专项组件：TV 焦点外发光卡片、毛玻璃悬浮播放器控制条、10 英尺 D-Pad 导航感知容器。
2. **默认深色与字体/图标合规**：
   - 播放器场景以深色模式（Cinema Dark）为默认值。
   - 严禁内置未经授权分发的 Apple 商业资产（如 SF Pro 字体、SF Symbols 图标）；使用系统字体或开源字体（Inter），图标使用开源图标库（Lucide / Phosphor）。
3. **低性能模式 (Low Performance Mode / R15 / APP-13)**：
   - 在应用设置中提供“低性能模式”开关，并在检测到弱硬件设备时可智能启用。
   - 开启低性能模式后，所有毛玻璃实时模糊（BackdropFilter）降级为**固定不透明度半透明纯色**（如 `Color(0xEE1E1E1E)`），并禁用高开销连续呼吸动效，严格遵守性能预算。

## 原因分析与权衡
1. **跨三端体验一致性**：
   - 统一采用 Cupertino 组件与 Apple 风格设计令牌，避免了不同平台风格混乱分裂的拼凑感。
2. **兼顾高端质感与低端流畅度**：
   - 高端设备展现影视级通透毛玻璃质感，低端盒子通过降级策略保持 60fps 遥控交互不卡顿。
