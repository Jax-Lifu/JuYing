# ADR-0002：聚类与元数据权威

状态：已接受  
日期：2026-08-19  
复审日期：2027-02-19

## 背景

来源标题、年份、分级和集序可能冲突，自动合并不可逆会误导用户。

## 备选方案

1. 第一个来源覆盖全部字段；2. 自动标题合并；3. 保留来源元数据、置信度与人工覆盖。

## 决定

采用方案 3。适配器保留来源标题、原分类标签、年份/地区和来源版本；低置信度不自动合并。人工覆盖必须可追溯、可撤销。

## 后果与迁移

通用 UI 只展示规范化字段；来源扩展字段不得扩散。后续聚类服务需记录合并理由和候选来源。

## 验收与复审触发条件

同名异片和重制版夹具不合并；引入人工运营台时复审。
