# ADR-009: 采用 GNU General Public License v3.0 (GPL-3.0) 作为项目开源协议

## 状态
已接受 (Accepted) (v0.2 N1 / 11.1)

## 日期
2026-10-20

## 背景与上下文
聚映项目定位于个人与社区开源聚合播放器。
在技术选型与协议实现中，涉及以下外部组件与开源参考库：
1. **UxPlay**：跨平台 AirPlay 接收端核心，基于 GPLv3 许可证发布。若将其编译并链接进分发物，整个分发包受 GPL 条款约束。
2. **开源参考项目**：社区优秀的开源播放器（如 DreamPlayer、FongMi/TV、Iris 等）采用 GPLv3 或 AGPL-3.0 协议。
3. **libmpv / FFmpeg**：包含部分 GPL 构建模块以获得最大格式解码支持。

## 决策
正式将项目整体许可证确立为 **GNU General Public License v3.0 (GPL-3.0)**，在项目根目录下维护标准的 `LICENSE` 文件。

## 原因分析与权衡
1. **扫清依赖集成法律障碍**：
   - 确定 GPL-3.0 后，可以直接编译并集成 UxPlay (C 源码/静态库)，无需规避强传染性约束。
2. **社区代码规范互通**：
   - 在保留原作者署名、版权声明并以兼容许可证发布的前提下，可合法参考甚至复用优秀的 GPL 开源实现。
3. **商业分发限制与个人开源定位吻合**：
   - 本项目定位于自用与公开发布开源版本，不涉及闭源商业化 SaaS 销售，GPL-3.0 强互惠约束能够有效防止核心逻辑被第三方无偿打包闭源转售。

## 规范要求
- 复用任何第三方 GPL 代码时，必须保留原始作者署名与版权头信息。
- 复用 AGPL 代码时需单独核对网络服务条款影响。
- 第三方原生库（libmpv、UxPlay）版本与构建校验值记录在 `docs/release-checklist.md`。
