# 聚映 (JuYing) 特性与演化路线图 (Feature Roadmap)

> 基线规范：依据《聚映项目指导文档 v0.1 (2026-10-20)》制定  
> 核心原则：统一播放内核（libmpv）、协议与 UI 解耦、内容不内置、10 英尺遥控器大屏原生适配。

---

## 阶段规划概览

```text
M0 技术验证 ──> M1 核心播放闭环 ──> M2 完整直播 ──> M3 NAS与点播 ──> M4 DLNA发送 ──> M5 DLNA接收 ──> M6 TVBox兼容 ──> M7 TV打磨与Beta
```

---

## 模块特性演化路线

### 1. 🎬 播放核心 (Player Engine - PLY)

- **当前基线**：
  - 基于 `media_kit` (libmpv) 跨平台统一内核；
  - 默认开启硬件解码，失败平滑降级至软解；
  - 3 秒卡顿看门狗监测与自动换线。
- **演进路线**：
  - **[PLY-04 / PLY-05] (P0/P1)**：多音轨与多字幕轨切换抽屉（清晰标注国语/粤语/原声，简中/双语）；本地挂载 `.srt`/`.ass`/`.vtt` 外挂字幕；字幕样式微调（字号、描边、垂直位置偏移）。
  - **[PLY-09 / PLY-10] (P1)**：Android 系统级画中画 (PiP) 与桌面端无边框置顶极简小窗；播放比例自由缩放（自适应、铺满、裁剪、16:9、4:3、21:9）。
  - **[PLY-11] (P1)**：智能连播与选集增强：单集播完前 10 秒倒计时无缝切集气泡；跳过片头/片尾记忆时间设置；列表顺序、随机、单集循环。
  - **[PLY-12] (P1)**：专业影音诊断浮层 (Stats for Nerds)：实时展示当前解码器、丢帧率、实时码率与缓冲健康度。
  - **[PLY-13] (P2 ⚠️)**：HDR 直通、音频 Passthrough（杜比/DTS 原生输出）。

---

### 2. 📺 直播中心与 IPTV (LIVE)

- **当前基线**：
  - 支持标准扩展 M3U 与 TXT 分组源导入，自动识别 UTF-8 / GBK 编码；
  - 预置 CCTV 官方示范源动态鉴权解析；
  - IPv4 / IPv6 双栈探测与多线路手动/自动切换。
- **演进路线**：
  - **[LIVE-05] (P1)**：后台低频测速与线路评分持久化，失败源进入动态冷却，优先使用用户手动选定的线路。
  - **[LIVE-06] (P1)**：流式解析 XMLTV (含 gz) 格式 EPG，关联当前播放与后续节目单预告；基于别名表与规范化名称进行频道精准匹配。
  - **[LIVE-08] (P1)**：10 英尺客厅快速换台体验：遥控器上下键快速换台、0-9 数字键台号直达（带 1.5s 防抖）、相邻频道预热机制。
  - **[LIVE-09] (P2 ⚠️)**：7 天时移回看能力：根据源配置中的 `catchup-source` 模板进行动态时间插值与时区修正。
  - **[LIVE-10] (P2)**：UDP / RTP 局域网组播直播流与内置 udpxy 转换。

---

### 3. 🕷️ 点播源与 TVBox 兼容层 (VOD)

- **当前基线**：
  - 支持 TVBox JSON、多仓 `dc.txt`、AES-128-CBC 与 WebP 混淆解密；
  - CMS 接口全平台原生支持；
  - 规范媒体实体 (`MediaItem`) 与站源候选 (`PlaybackCandidate`) 彻底解耦（Animeko 模式）。
- **演进路线**：
  - **[VOD-04] (P1 ⚠️)**：完善跨平台 QuickJS 爬虫沙箱（drpy 系列）：注入安全受控宿主 API，限制 32MB 内存硬上限与 6 秒网络硬超时，杜绝本地网络未授权扫描。
  - **[VOD-06] (P1)**：源健康检查与平台兼容性指示：平台不支持的站点（如 Windows 运行 Jar 爬虫）显式置灰并提示原因，坚决不使用虚假 mock 误导用户。
  - **[VOD-07] (P2 ⚠️)**：Android 平台可选 Jar / Dex 爬虫运行时（默认关闭，需用户显式开启与授权）。
  - **[VOD-08] (P2 ⚠️)**：网页解析接口（parses）与无头嗅探支持。

---

### 4. 📁 本地与局域网 NAS (LIB)

- **当前基线**：
  - 本地文件与目录浏览播放；
  - 局域网 SMB (SMB2/3)、WebDAV 浏览与流式桥接。
- **演进路线**：
  - **[LIB-03] (P0)**：深度兼容 Alist WebDAV 虚拟挂载，实现网盘资源向标准流媒体协议的间接转换（ADR-005/ADR-006）。
  - **[LIB-04] (P1)**：同目录外挂字幕（`.srt`, `.ass`）自动模糊匹配并自动挂载。
  - **[LIB-06] (P1)**：NAS 断网自动重连与针对大体积 MKV 视频尾部索引定位的 Range 请求专项优化。
  - **[LIB-09] (P2)**：TMDB / 豆瓣元数据智能刮削与影视海报墙聚合。

---

### 5. 📡 投屏与多屏互联 (CAST & DMR & APL)

- **当前基线**：
  - 本地微型 Range 代理服务（`127.0.0.1:9978`）；
  - 局域网远程配置门户（支持手机推送源与配置）。
  - DLNA DMC 基础发现与投送。
- **演进路线**：
  - **[CAST-01 ~ CAST-05] (P0/P1)**：完善 DLNA 发送端：支持手动输入电视 IP 兜底；支持完整的 Play / Pause / Seek / 音量调节 / 进度双向同步遥控；建立电视设备兼容性画像库 (DeviceProfile)。
  - **[DMR-01 ~ DMR-07] (P1)**：完整落地 DLNA 接收端：被手机主流视频 App 发现；响应 AVTransport / RenderingControl；Android 前台服务 + MulticastLock 保活；Windows 托盘常驻与防火墙放行引导。
  - **[APL-01 ~ APL-05] (P2 ⚠️)**：AirPlay 接收端实验特性：基于 UxPlay 与 JNI 桥接验证音频接收与屏幕镜像，严格做好 GPLv3 许可证隔离。

---

### 6. 📱 跨端通用体验与大屏优化 (APP)

- **当前基线**：
  - GoRouter 声明式路由与响应式布局；
  - 遥控器 `TvFocusWrapper` 焦点放大与高亮外框；
  - 本地脱敏日志捕获。
- **演进路线**：
  - **[APP-01 / APP-10] (P0/P1)**：源管理中心与首次启动空状态引导向导（添加源 / 导入配置 / 扫码配置）。
  - **[APP-04] (P1)**：10 英尺客厅遥控器 D-Pad 交互全覆盖审计（所有页面与弹窗具备可感知焦点）。
  - **[APP-05] (P1)**：桌面系统深度集成（SMTC 系统媒体控件、全局键盘媒体快捷键、托盘最小化）。
  - **[APP-07] (P1)**：版本化 Schema 配置导出与备份恢复（含敏感凭据安全脱敏）。
  - **[APP-08] (P1)**：应用内静默检查更新（GitHub Releases / 自建 CDN）。
