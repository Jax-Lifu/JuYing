# 统一媒体契约

这是聚映的唯一多源边界。它规定不同来源如何进入同一套目录、分类、搜索、选集和播放器体验；不是任何来源的抓取说明，也不授权绕过内容保护。

## 规范化流程

```text
来源适配器
  → 原始目录/详情/搜索/播放元数据
  → 授权、地区、儿童与设备策略
  → 统一目录、统一媒体条目、统一季/集、统一播放描述
  → 分类页 / 全局搜索 / 详情选集 / 播放器
```

来源适配器是唯一允许认识来源特有字段、URL、认证方式和分类名称的层。其余层只使用下列统一语义。

## 统一实体

| 实体 | 必填语义 | 说明 |
|---|---|---|
| 来源 | `sourceId`、名称、类型、启用状态、授权状态、能力、健康状态 | 来源 ID 全局唯一且不可因显示名变化而变化。 |
| 媒体条目 | `sourceId`、`sourceItemId`、标题、类型、分类、详情入口 | 跨源稳定键为 `sourceId:sourceItemId`。 |
| 作品聚类 | 规范化标题、年份/季、类型、可选外部权威 ID、候选来源 | 仅用于聚合展示；不取代来源内身份。 |
| 季/集 | 作品来源键、季号、集号/特别篇序号、标题、播放候选来源 | 集序缺失时使用来源稳定序号并标注未知。 |
| 搜索命中 | 查询、来源键、匹配字段、得分、可播放状态、聚类键 | 每个命中必须可回溯到来源。 |
| 播放描述 | 来源键、集键、已授权 URI、过期时间、轨道/字幕/清晰度、限制 | 只在当前会话持有 URI；禁止写入长期存储。 |

## 固定分类与映射

所有来源都要向以下八类之一映射，并同时保留 `sourceCategoryLabel` 供诊断与来源筛选：

| 统一分类 | 典型来源标签 | 儿童空间默认策略 |
|---|---|---|
| 电视剧 | 电视剧、剧集、连续剧 | 需年龄分级后展示 |
| 电影 | 电影、影片 | 需年龄分级后展示 |
| 动画片 | 动画片、动漫、卡通 | 可作为儿童候选，但仍需年龄策略 |
| 纪录片 | 纪录片、纪实 | 需年龄分级后展示 |
| 综艺 | 综艺、节目、晚会 | 需年龄分级后展示 |
| 直播 | 直播、频道 | 受地区、时段和车机策略影响 |
| 少儿 | 少儿、亲子、教育 | 仍需家长档案过滤 |
| 其他 | 无法可靠归类的合法内容 | 默认不进入儿童推荐 |

分类映射表必须数据驱动、可审查、可按来源版本维护。UI 不得显示来源的分类编码，也不得在 UI 中写来源名称判断。

## 来源能力与统一操作

| 能力 | 允许的统一操作 |
|---|---|
| `browse` | 出现在分类页、来源筛选与详情跳转。 |
| `search` | 进入联邦搜索扇出集合。 |
| `episodes` | 在统一选集页提供季/集列表。 |
| `playAuthorizedMedia` 或 `nativePublicPlayback` | 产生统一播放描述并可进入原生播放器。 |
| `officialFallback` | 原生播放不可用时可打开官方入口。 |
| `subtitles` / `audioTracks` / `qualitySelection` | 对应播放器选择器按实际能力显示。 |
| `continueWatching` | 保存/恢复来源内集键与进度。 |
| `offlineDownload` | 必须同时声明许可、到期和存储规则。 |

来源缺少某项能力时，相关操作在该来源范围内不可用；不能通过其他来源的能力推断其支持。

## 默认来源基线

默认来源标识为 `cctv-official`，默认入口为用户指定的 CCTV 动画片库：

`https://tv.cctv.com/yxg/index.shtml?spm=C28340.P2qo7O8Q1Led.EEfEAhEnQFPl.64#datacid=dhp&datafl=&datadq=&fc=%E5%8A%A8%E7%94%BB%E7%89%87&dataszm=`

它的默认统一分类是“动画片”。不同于首页入口，来源适配器仍须能返回其它来源实际提供且可合法使用的统一分类；不得把“动画片”硬编码为全局唯一分类。
