# 内容与合规边界

## 默认 CCTV 来源

配置中的 `https://tv.cctv.com/yxg/index.shtml` 是 CCTV 节目官网片库入口。当前适配器复用页面自身公开调用的数据链路：

- 从 `api.cntv.cn` 获取公开片库数据；
- 只读取节目页显式声明的 `guid`；
- 从 `vdn.apps.cntv.cn` 获取页面播放器同源的播放元数据；
- 仅接受响应中的公开 HTTPS HLS 地址，并限制为 CCTV/CNTV 相关域名；
- 不绕过签名、鉴权、DRM、广告、区域或终端限制；
- `is_protected` 或版权无效时拒绝原生播放并跳转官网；
- 不持久化播放地址、不下载、不转播、不二次分发央视内容。

这些 Web 接口并非正式对外承诺稳定的开放 API，页面结构、字段和 CDN 策略随时可能变化。未取得书面授权前，来源授权状态保持 `unknown`；生产发布应确认许可地区、设备、时段、内容类别与缓存政策。

## “免费观看”的定义

本项目中的免费内容只能来自：

1. 权利方明确允许免费访问且允许当前接入方式的内容；
2. 用户拥有或有权访问的本地/NAS 内容；
3. 已签署授权协议的第三方服务。

用户自定义来源需要显式确认权利与风险。应用商店版本应提供来源下架、投诉、家长控制、隐私政策和数据清除入口。
