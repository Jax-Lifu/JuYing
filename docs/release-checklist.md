# 聚映 (JuYing) 正式版本发布检查清单 (Release Checklist)

> 基线版本：依据《聚映项目指导文档》第 10.4 节与第 3.5 节合规要求制定

---

## 1. 法律合规与开源许可 (Legal & Compliance)

- [ ] **严禁内置任何第三方媒体流**：
  - 检查客户端 assets 与代码，确认不包含任何未经授权的第三方视频流、侵权源或商业直播 URL。
  - 默认 CCTV 示例源有明确合法出处，且允许用户一键停用与删除。
- [ ] **免责声明与隐私协议**：
  - 首次启动弹窗展示免责声明（“本软件为纯本地播放与网络流媒体播放工具，不内置或运营任何内容”）。
  - 设置中心常驻“隐私协议”与“免责声明”查看入口。
- [ ] **第三方开源许可证清单 (About & Licenses)**：
  - 应用内置“关于我们”和“第三方开源许可致谢”页面，分发包附带 GPL-3.0 `LICENSE` 全文。
  - 项目正式以 **GPL-3.0** 开源发布（ADR-009），直接集成 UxPlay（GPLv3）并合规复用社区 GPL 参考项目。
  - 核心原生依赖（libmpv、UxPlay 等）使用脚本从固定版本构建，并记录来源与 SHA-256 校验值。
- [ ] **商标合规**：
  - 避免在官方宣传中违规滥用 “AirPlay”、“DLNA” 官方商标，规范表述为“兼容 UPnP AV / DLNA 协议”、“兼容 AirPlay 协议接收”。

---

## 2. 跨平台构建与产物完整性 (Build & Artifacts)

- [ ] **Windows 桌面端**：
  - 生成便携版绿色压缩包 (`.zip`) 与标准安装程序（Inno Setup / NSIS 或 MSIX）。
  - 执行可执行文件与 DLL 签名，避免 Windows SmartScreen 拦截。
  - 针对 Windows Defender 常见误报规则进行上线前体检。
  - 验证 VC++ 运行库在纯净 Windows 10/11 虚拟机上的依赖完整性。
- [ ] **Android / Android TV 移动端**：
  - 提供分 ABI 独立 APK 包（`arm64-v8a` 为主力，`armeabi-v7a` 供老旧盒子选用），或提供通用包。
  - 生产密钥签名（Release Keystore）严格通过 CI/CD 环境变量注入，禁止密钥硬编码落盘。
  - 验证 Android 14 前台服务声明、网络安全配置（HTTP 明文放行）以及 TV Leanback Banner 图标。

---

## 3. 架构韧性与数据迁移 (Resilience & Migration)

- [ ] **配置 Schema 迁移与备份**：
  - 检查 `schema_version` 是否已递增，验证从上一版本升级启动时自动迁移旧数据库与 JSON 配置。
  - 启动前自动执行一次用户旧配置 `.bak` 备份，发生反序列化异常时自动安全降级，绝不白屏崩溃。
- [ ] **长稳与性能验收**：
  - Windows 端与 Android 端分别通过 24 小时连续流媒体播放无崩溃、无内存泄漏。
  - DMR 接收端局域网常驻待机 7 天，被投屏响应正常。
- [ ] **本地脱敏日志导出验证**：
  - 在设置页点击“导出日志”，确认生成的日志包已对 URL Token、账户密码与私人网段信息执行了掩码过滤。
- [ ] **用户排障指引 (FAQ) 完备度**：
  - 随发布说明提供常见排障指南，重点覆盖第一高频问题：“局域网内搜索不到电视 / 投屏失败如何排查（AP隔离、防火墙、同一Wi-Fi频段）”。
