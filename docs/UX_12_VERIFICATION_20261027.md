## 文件浏览与播放

本机、移动存储和已配置 NAS 都在应用内浏览；文件入口不再打开系统文件选择器。Android 11 及以上通过系统设置授予文件访问，Android 9/10 使用存储权限。权限页面仅负责授权，返回后仍使用应用内文件页。

`StorageUiTest` 两项在本轮设备日志中通过：

- 本机根目录 → Download → 独立测试目录 → 真实 PlayerActivity，验证 320×240、进度推进、seek、同目录中文字幕轨，以及返回原目录。
- 旧授权目录的 `content://` 视频及同目录字幕继续可读，并可在原生 Surface 上解码和 seek。

`SmbStorageUiTest` 使用 `smbFixtureUrl`、`user`、`password` 参数，在最终设备回归中执行并通过，确认目录点击、真实 PlayerActivity、320×240、进度、seek、字幕和返回目录。测试服务仅绑定主机回环地址，经设备转发访问，只读共享中仅放置自制测试视频和字幕；凭据不写入本文。该结果不能替代真实 NAS、账号差异、网络中断或实物 USB 插拔验收。

## 原生点播与上游边界

CCTV 高清移植自旧 Flutter 工程提交 `331aa2972d2d4f4ec0b9c4f888632f0d36105310`，接入 Android JNI 与 Media3，保留第三方来源和许可证说明。本轮真网测试记录了两集 1280×720：首集时长 439480 ms，进度推进至约 3 秒、前跳约 121 秒、回退约 21 秒；第二集时长 439800 ms。真实 PlayerActivity/Hilt 路由也完成两集播放并取得 20 集列表，未进入网页播放。测试包含 Surface 截帧检查。

当前支持 H5E/H.264 TS 点播，不包含 UDRM、Widevine 或 HEVC。最高档编码或清单不支持时明确报错，不自动降为标清；标清须手动选择。点播不提供网页入口，旧官方网页历史自动解析为原生高清，继续支持原进度、选集与下一集。央视直播网页入口保持原行为。长时连续播放、音频实听及更多节目尚未验收。

TVBox 的 `parse=1` / `jx=1` 会尝试订阅声明的 type 1 JSON 解析器；成功后以媒体地址和相应请求头进入原生播放，未解析出原生地址则显示受控错误，不打开 WebView，也不破坏当前节目的播放、备用线路或选集加载。解析器选择、请求头隔离、取消及拒绝网页路由已有单测；CMS 原生解码及原创 Jar/JS/Python 设备测试通过。公开订阅探测本轮未传参数，两个方法均跳过。完整 drpy 桥、通用网页嗅探、私有依赖及上游 403/鉴权限制仍需逐站核实，不能由测试片通过推断所有站点可播。
